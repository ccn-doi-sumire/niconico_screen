# Meet Comment Overlay

<img width="720" height="405" alt="demo" src="https://github.com/user-attachments/assets/4c4bd66e-cae8-47fe-9d36-09bba893b700" />

Google Meet のチャットとリアクションを、デスクトップの上にニコニコ動画風に流すツールです。
発表者が画面共有しているスライドの上に、参加者のコメントが右から左へ、リアクションの絵文字が下から上へ流れます。

専用のコメントページやルームは不要で、参加者はいつもどおり Meet のチャットとリアクションを使うだけです。
Google の公式ツールではありません。

## しくみ

2つの部品で動きます。どちらもインストール作業は不要です。

| 部品 | 役割 |
|---|---|
| Chrome 拡張（`extension/`） | Meet のタブからチャットとリアクションを拾う |
| オーバーレイ（`overlay/`） | デスクトップ最前面の透明なウィンドウに流す |

オーバーレイは OS に標準で入っている機能だけで動きます（Mac は `osascript`、Windows は PowerShell + WPF）。
拡張とオーバーレイは、同じ PC の中（`127.0.0.1:39393`）だけで通信します。コメントの内容が外部に送られることはありません。
リアクションの動く絵文字の画像だけ、Google Fonts（`fonts.gstatic.com`）から読み込みます。

## 使い方

### 1. オーバーレイを起動する（発表する PC で）

- **Mac**: `start-mac.command` をダブルクリック。メニューバーに 💬 が出ます。
- **Windows**: `start-windows.bat` をダブルクリック。タスクトレイにアイコンが出ます。

終了は、そのアイコンのメニューから「終了」を選びます。

### 2. Chrome 拡張を読み込む（初回だけ）

1. Chrome で `chrome://extensions` を開く
2. 右上の「デベロッパー モード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」を押して、`extension` フォルダを選ぶ

### 3. Meet に参加する

Meet のタブを開く（すでに開いていた場合は再読み込みする）と、右下のボタン群のいちばん左に、
モニターと吹き出しのボタンが増えます。これが表示のオン／オフです。

オンの間、チャットとリアクションがデスクトップに流れます。

## 設定

Chrome のツールバーで拡張のアイコンを押すと、設定パネルが開きます。

- **表示する画面**: モニターを複数つないでいるとき、どの画面に流すか
- **文字サイズ**: 小さめ・標準・大きめ・特大
- **流れる速さ**: ゆっくり（9秒）・標準（6秒）・速い（4秒）
- **NGワード**: 含まれるコメントを流さない（1行に1件。大文字・小文字、全角・半角は区別しません）
- **テストする**: 選択中のサイズ・速さでテスト用のコメントを流す

サイズ・速さ・NGワードは「保存する」で反映されます。

## 動作確認の状況と制限

- **確認した環境**: macOS + Chrome。Windows 版は構文チェックと一部ロジックの確認だけで、**実機では未確認**です。
- **拡張が必要なのは発表者だけ**です。発表者の Meet タブが開いている間だけ拾えます。
- **リアクションの数**: 届いたリアクションは、1個ずつすべて表示します。まとめたり間引いたりはしません。
  画面上の数が多いときは、Meet と同じように小さめの静止画で描きます。
  なお、Meet 自体が連打されたリアクションを減らして配信することがあり、届かなかった分は表示できません。
- **チャット**: Meet の新着通知と、チャット欄（Google Chat の埋め込み）の両方から拾います。
  チャット欄を開いたときに出てくる過去のメッセージは流しません。
- **Meet の画面構成に依存**しています。Meet 側の変更で拾えなくなることがあります。

## うまく動かないとき

- **拡張のパネルに「オーバーレイが起動していません」と出る**: 手順1のオーバーレイを起動してください。
- **何も流れない**: Meet 右下のボタンがオフ（斜線）になっていないか確認してください。
  拡張を更新した直後は、Meet のタブの再読み込みが必要です。
- **表示だけ試したい**: オーバーレイのメニューから「テスト送信ページを開く」を選ぶと、Meet なしでコメントを流せます。

調査用に、オーバーレイは次の情報をローカルで返します。

| URL | 内容 |
|---|---|
| `http://127.0.0.1:39393/debug` | オーバーレイのウィンドウの状態 |
| `http://127.0.0.1:39393/log` | 最近受け取ったコメントと、その経路（Mac 版のみ） |
| `http://127.0.0.1:39393/diag` | 拡張から届いた診断情報（Meet の画面構造など。Mac 版のみ） |

## フォルダ構成

```
extension/            Chrome 拡張
  capture.js          Meet のページ内でリアクションと通知を拾う
  chat-frame.js       チャット欄（Google Chat の埋め込み）からメッセージを拾う
  bridge.js           ページと拡張の間の受け渡し
  background.js       設定の適用とオーバーレイへの送信
  popup.html / .js    設定パネル
overlay/
  mac-overlay.js      Mac 用オーバーレイ（osascript / JXA）
  win-overlay.ps1     Windows 用オーバーレイ（PowerShell + WPF）
  overlay.html        Mac 用の描画ページ
  test.html           テスト送信ページ
tools/
  make-icons.swift    拡張のアイコンを生成するスクリプト
```
